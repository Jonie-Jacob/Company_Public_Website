## 2. Brand Identity

### Logo
- A crystalline, faceted **"Z"** rendered in blue-to-teal gradients, evoking a sapphire gem
- The logo communicates **precision, brilliance, trust, and innovation**
- The logo will be used as a subtle background watermark throughout the website (glassmorphism style)

### Color Palette

| Color | Role | Usage |
|-------|------|-------|
| **Deep Purple** (#6A0DAD) | Primary Accent | Buttons, headings, highlights, hover effects |
| **Ceylon Blue** (#0047AB) | Secondary Accent | Links, secondary elements, gradients |
| **Champagne** (#F7E7CE) | Warm Highlight | Text accents, dividers, subtle emphasis |
| **Teal-to-Blue Gradient** | Brand Gradient | Backgrounds, hero sections, cards |
| **Purple-to-Blue Gradient** | Feature Gradient | Section transitions, overlays |
| **Dark Charcoal** (#1A1A2E) | Background | Primary dark mode background |
| **Near Black** (#0F0F1A) | Deep Background | Footer, alternate sections |
| **White / Light Gray** | Text | Body text, headings |

### Typography Direction
- **Headings:** Bold, modern sans-serif (e.g., Inter, Poppins, or similar)
- **Body Text:** Clean, highly readable sans-serif
- **Accent/Tagline:** Semi-bold or italic for emphasis

## 7. Design Direction & Visual Style

### Overall Aesthetic
**Premium dark-mode experience** with vibrant accent colors, depth, and polish — a website that feels like a luxury product.

### Key Design Elements

| Element | Description |
|---------|-------------|
| **Dark Mode** | The entire website uses a dark theme with dark charcoal (#1A1A2E) and near-black (#0F0F1A) backgrounds |
| **Gradient Backgrounds** | Smooth gradients transitioning between purple, Ceylon blue, and teal across sections |
| **Glassmorphism** | Frosted glass effect on cards, navigation bar, and overlays — semi-transparent with backdrop blur |
| **Logo Watermark** | The Zyphr "Z" appears as a large, subtle, semi-transparent background element in hero sections |
| **Depth & Layering** | Multiple visual layers — background particles, mid-ground content, foreground elements — to create 3D depth |
| **Whitespace** | Generous spacing between sections to let the content breathe |
| **Consistency** | Uniform card styles, button styles, and typography across all pages |

### Responsive Design

| Breakpoint | Behavior |
|------------|----------|
| **Desktop** (1200px+) | Full layout with all effects, parallax, and animations |
| **Tablet** (768px–1199px) | Adapted grid layouts, touch-optimized interactions |
| **Mobile** (below 768px) | Single-column layout, hamburger menu, reduced animation for performance |

## 8. Interactive Features & Animations

### Parallax Scrolling
- **Hero sections:** Background elements (particles, logo watermark) move at a slower rate than foreground content, creating depth
- **Between sections:** Subtle parallax transitions as content scrolls in and out
- **Service cards:** Float effect as background shifts beneath them

### Interactive Cursor
- **Default state:** Custom cursor (small glowing dot or crosshair matching brand colors)
- **Hover on links/buttons:** Cursor expands with a glow effect
- **Hover on cards:** Cursor transforms (e.g., "View" text or expand icon)
- **Trail effect:** Subtle trailing particles or glow following the cursor
- **Mobile:** Disabled (not applicable to touch screens)

### Microinteractions

| Interaction | Animation |
|-------------|-----------|
| **Button hover** | Gentle scale-up + color shift + glow |
| **Button click** | Subtle press-down + ripple effect |
| **Card hover** | Lift (shadow increase) + border glow + icon animation |
| **Nav link hover** | Underline slides in from left |
| **Scroll reveal** | Content sections fade/slide in as they enter the viewport |
| **Page load** | Logo animation → tagline types in → content fades in |
| **Form field focus** | Border color transitions to accent color + subtle glow |
| **Form submit** | Button transforms into loading spinner → success animation (sparkle) |
| **Social icon hover** | Icon fills with brand color + gentle bounce |
| **Scroll-to-top** | Floating button appears after scroll, gently pulses |
| **Section transitions** | Smooth gradient color shifts as user scrolls between sections |
| **Number counters** | (Future) Stats/metrics count up when scrolled into view |

### Loading & Transitions
- **Page load:** Elegant loading animation with the Zyphr "Z" forming from particles
- **Page transitions:** Smooth fade or slide transitions between pages (if SPA)
- **Lazy loading:** Images and heavy content load gracefully with skeleton screens or fade-in
